# Code of Conduct

## Our Pledge

We are committed to making this project a welcoming and respectful environment for everyone.

## Expected Behavior

* Treat all contributors with respect.
* Provide constructive feedback.
* Focus discussions on ideas and improvements.
* Welcome different perspectives.
* Communicate clearly and professionally.

## Unacceptable Behavior

* Harassment or personal attacks
* Discriminatory language
* Deliberate disruption of project discussions
* Sharing private information without permission

## Reporting Issues

Report inappropriate behavior privately to the repository maintainer.

## Scope

These guidelines apply to project discussions, issues, pull requests, and other community spaces associated with this repository.

## Our Goal

Help everyone contribute to an open, collaborative, and positive learning environment.
