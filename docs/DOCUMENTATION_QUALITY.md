# Documentation Quality

## Accuracy
- Verify facts, commands, and examples.
- Keep links relevant and up to date.
- Do not present assumptions as confirmed facts.

## Clarity
- Use simple, direct language.
- Explain unfamiliar terms.
- Keep paragraphs focused on one topic.

## Structure
- Use headings to organize information.
- Keep heading levels consistent.
- Use lists for steps and related items.

## Consistency
- Follow the project's documentation style guide.
- Use consistent terminology and formatting.
- Keep file names descriptive.

## Maintenance
- Review documentation when project behavior changes.
- Remove outdated instructions.
- Check internal and external links.

## Review Checklist
- [ ] The purpose of the document is clear.
- [ ] Instructions are accurate and complete.
- [ ] Formatting is consistent.
- [ ] Links and examples have been checked.
- [ ] Spelling and grammar have been reviewed.

High-quality documentation helps contributors understand and use the project.
