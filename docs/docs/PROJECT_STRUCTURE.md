# Project Structure

## Overview
This repository contains project documentation and contribution resources.

## Main Files
- README.md — project overview and introduction.
- CONTRIBUTING.md — contribution guidelines.
- CODE_OF_CONDUCT.md — community behavior standards.
- SECURITY.md — security reporting policy.
- SUPPORT.md — support information.
- CHANGELOG.md — project change history.
- ROADMAP.md — planned improvements.
- LICENSE — license information.

## Documentation Directory
The docs/ directory contains additional guides:
- GETTING_STARTED.md — introduction for new contributors.
- FAQ.md — answers to frequently asked questions.
- PROJECT_GOALS.md — project purpose and principles.

## Keeping It Organized
New documentation should be placed in the most relevant directory and linked from the README when appropriate.
