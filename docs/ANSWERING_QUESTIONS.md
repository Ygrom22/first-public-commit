# Answering Questions

## Be Clear
Use simple language and explain technical terms when necessary.

## Be Helpful
Focus on solving the question. Include examples or links when they are useful.

## Be Respectful
Treat every question seriously and respond in a friendly, constructive way.

## Verify Information
Check facts before sharing them. If you are unsure, say so.

## Structure Your Answer
- Start with the main answer.
- Add steps or examples if needed.
- Include relevant documentation links.
- Explain any important limitations.

## Follow Up
Ask for more details when the question is unclear. Update your answer if new information changes it.

Helpful answers make the project easier to understand and contribute to.
