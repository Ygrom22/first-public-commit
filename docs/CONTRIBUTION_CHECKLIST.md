# Contribution Checklist

Use this checklist before submitting a contribution.

## Before Starting
- [ ] Read the README.md.
- [ ] Review the CONTRIBUTING.md guidelines.
- [ ] Check existing issues to avoid duplicate work.
- [ ] Make sure the proposed change fits the project goals.

## Before Submitting
- [ ] Keep changes focused and easy to review.
- [ ] Check spelling and formatting.
- [ ] Update documentation when needed.
- [ ] Provide a clear commit message.
- [ ] Review the final changes.

## After Submitting
- [ ] Respond politely to feedback.
- [ ] Make requested improvements when appropriate.
- [ ] Keep discussion constructive.

Thank you for helping improve this project!
