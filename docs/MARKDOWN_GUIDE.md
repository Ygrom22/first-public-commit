# Markdown Guide

## Overview
Markdown is a lightweight format for writing readable documentation.

## Headings
Use the # symbol to create headings.

# Heading 1
## Heading 2
### Heading 3

## Text Formatting
- Use **bold** for important text.
- Use *italic* for emphasis.
- Use `inline code` for commands and file names.

## Lists
Unordered list:
- First item
- Second item

Ordered list:
1. First step
2. Second step

## Links
Use descriptive link text:
[GitHub](https://github.com)

## Code Blocks
Use triple backticks to format multiple lines of code.

## Checklists
- [ ] Task to complete
- [x] Completed task

## Best Practices
- Keep formatting consistent.
- Use headings to organize long documents.
- Write descriptive link text.
- Preview the rendered document before committing.

Good Markdown makes project documentation easier to read.
